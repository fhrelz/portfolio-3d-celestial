## ✨ Fitur Unggulan

- **🌕 3D Interactive Realistic Supermoon**:
  - Model 3D bola bulan berskala kolosal dengan topografi 4K NASA LROC & Bump Map relief tinggi.
  - Interaksi 360° drag rotasi dengan inersia momentum halus.
  - Interactive Hotspot Markers untuk navigasi landmark pencapaian (*Mare Tranquillitatis*, *Copernicus*, *Tycho*, *Oceanus Procellarum*).
  - Kontrol eksplorasi lengkap: Zoom In, Zoom Out, Auto-Rotate, Lunar Light Phase Switcher, dan View Mode Toggle.
- **✨ Ultra-Realistic Three.js Starfield**:
  - 4.500 bintang dengan kedalaman astronomis dan simulasi spektral warna bintang (*Class O, B, A, F, G, K*).
  - Shimmering diffraction spikes glints pada bintang-bintang gem cerah.
  - Sistem partikel Meteor / Bolide (bintang jatuh) dengan ribbon trail dinamis.
  - Komet megah ber-ion tail yang melesat melintasi angkasa luar.
- **🎵 Web Audio API Procedural Soundscape & Interactive SFX**:
  - *Backsound* ambien kosmik pad *F# minor 9* hangat + dentingan lonceng starlight (*procedural sound, zero mp3 files*).
  - SFX interaktif: Crystalline starlight hover ping, tactile cosmic click snap, space gravity whoosh saat scrolling, dan glissando zoom frequency sweep.
  - Audio FX khusus saat bintang jatuh atau komet melintas di langit.
- **📄 Curriculum Vitae ATS Ready**:
  - Halaman khusus `cv-ats.html` standar industri ATS, dioptimalkan untuk scanning mesin rekrutmen global, lengkap dengan tombol Download PDF & Print.
- **🌐 Multilingual Engine**:
  - Dukungan dwibahasa instan: Bahasa Indonesia 🇮🇩 dan Bahasa Inggris 🇬🇧.
- **🌓 Deep Obsidian Cosmos Design System**:
  - Tema hitam pekat luar angkasa murni (*True Obsidian Black `#000000`*) yang mempertegas pendar bintang dan kontras tipografi Outfit & Space Grotesk.

## 🛠️ Teknologi & Stack

- **Core**: HTML5, Vanilla CSS3 (Custom Design System & Glassmorphism), Vanilla JavaScript (ES6+)
- **3D Graphics Engine**: [Three.js](https://threejs.org/) (r128 WebGL Renderer)
- **Audio Synthesis**: Web Audio API (Overtone Oscillators, Biquad Filters, LFO Gain Modulation)
- **Iconography & Fonts**: FontAwesome 6, Google Fonts (*Outfit*, *Plus Jakarta Sans*, *Space Grotesk*)

## 🚀 Menjalankan Secara Lokal

1. Clone repositori ini:
   ```bash
   git clone https://github.com/itsrelzzz/portfolio-3d-fahrel.git
   ```
2. Buka folder proyek:
   ```bash
   cd portfolio-3d-fahrel
   ```
3. Jalankan server lokal sederhana (misalnya menggunakan Python):
   ```bash
   python -m http.server 8080
   ```
4. Buka browser dan akses:
   ```
   http://localhost:8080
   ```
